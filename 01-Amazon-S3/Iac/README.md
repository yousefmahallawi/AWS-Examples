# Infrastructure as Code (IaC)

This folder contains examples of creating an Amazon S3 bucket using different Infrastructure as Code tools.

## Tools Covered

- AWS CloudFormation
- Terraform
- AWS CDK (TypeScript)
- Pulumi (Python)

## Why IaC?

Infrastructure as Code allows cloud resources to be defined in source code instead of being created manually through the AWS Management Console.

Benefits include:

- Repeatable deployments
- Version control
- Automation
- Consistent environments
